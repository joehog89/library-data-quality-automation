# User Stories and Kanban Board

The Kanban board was used to track work through the To do, In progress and Done stages.

| To do | In progress | Done |
|---|---|---|
| None | As a developer, I want to update the README so that the project is clearly documented. | As a library user, I want CSV data to be cleaned automatically so that manual work is reduced. |
|  |  | As a library user, I want missing values to be identified so that incomplete records are removed. |
|  |  | As a library user, I want duplicate loans to be removed so that the results are reliable. |
|  |  | As a developer, I want automated tests so that incorrect changes are identified. |
|  |  | As a developer, I want GitHub Actions to run the tests so that every update is checked. |
|  |  | As a developer, I want the application packaged with Docker so that it can run consistently. |
|  |  | As a library user, I want a simple dashboard so that I can understand the cleaned data. |

## Kanban process

- **To do:** Work that has not been started.
- **In progress:** Work currently being completed.
- **Done:** Work that has been completed and tested.
